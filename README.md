# 🏠 House Price Prediction

This project focuses on predicting house prices using machine learning techniques. It uses the California housing dataset and applies regression models to estimate house values based on different features.

---

## 📌 Features

* Data loading using `sklearn.datasets`
* Data preprocessing and exploration
* Train-test split for model evaluation
* Model training using **XGBoost Regressor**
* Performance evaluation using metrics

---

## 🛠️ Tech Stack

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* XGBoost

## 🚀 How to Run

1. Clone the repository:

```
git clone https://github.com/ManasDeveshTrivedi/House-Price-Prediction
```

2. Navigate to the project folder:

```
cd P1_HousePrice_Prediction
```

3. Install dependencies:

```
pip install numpy pandas matplotlib seaborn scikit-learn xgboost
```

4. Run the notebook:

```
jupyter notebook
```
